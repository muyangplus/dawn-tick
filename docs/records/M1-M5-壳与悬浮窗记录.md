# M1 收尾 与 M5 — 壳、原生存储与悬浮窗/小组件记录

日期：2026-10-10

## 1. 工程结构

| 目录 | 内容 |
|---|---|
| `apps/web` | Web 与三端共用的界面；双入口（`index.html` 主窗口、`mini.html` 紧凑条） |
| `apps/desktop` | Tauri 2 壳（Rust）：窗口、托盘、SQLite 插件与迁移 |
| `apps/mobile` | Capacitor 壳与 Android 工程：SQLite 与本地通知插件、两种主屏小组件 |
| `packages/core` | 跨端共用的领域逻辑与存储抽象 |

## 2. 存储接入

| 端 | 实现 | 说明 |
|---|---|---|
| Web | `apps/web/src/db/idb-storage.ts` | IndexedDB |
| Windows | `tauri-driver.ts` + `sqliteStorage` | `tauri-plugin-sql`；表结构由 Rust 侧迁移建立 |
| Android | `capacitor-driver.ts` + `sqliteStorage` | `@capacitor-community/sqlite`；表结构由共享 SQL 迁移建立 |
| 测试 | `node:sqlite` | `SqlDriver` 已改为异步，三端驱动接口一致 |

`apps/web/src/db/platform.ts` 负责探测平台并选择存储；原生 SQLite 不可用时回退 IndexedDB。

## 3. 通知调度

| 端 | 方式 | 应用关闭后 |
|---|---|---|
| Android | `@capacitor/local-notifications` 提前排定 | 可送达 |
| Windows | 常驻托盘 + 页面内计时触发 | 托盘常驻期间可送达 |
| Web | 页面内计时触发 + Notification API | 不可送达（D71） |

## 4. Windows 紧凑条与托盘

| 项 | 内容 |
|---|---|
| 窗口 | `mini`：240×104，无边框、置顶、跳过任务栏、透明背景、默认隐藏 |
| 拖动 | `data-tauri-drag-region` |
| 内容 | 下一节课、倒计时（每秒刷新）、开始时间与地点；数据每 60 秒重载 |
| 托盘 | 菜单：显示主窗口 / 显示紧凑条 / 隐藏紧凑条 / 退出；左键切换紧凑条 |
| 关闭行为 | 主窗口关闭改为隐藏，进程常驻（D29） |
| 编译 | `cargo check --all-targets` 通过 |

## 5. Android 主屏小组件

| 项 | 内容 |
|---|---|
| 2×2 | 下一节课与倒计时（`NextLessonWidget`） |
| 4×2 | 今日课表最多 5 条（`TodayWidget`） |
| 数据来源 | `app_meta.widget_snapshot`，由 Web 层每次加载后写入；小组件只读快照，不重复实现课表逻辑 |
| 刷新 | 数据变更后由 `WidgetRefresh` 插件即时刷新；另有 30 分钟周期与解锁（`ACTION_USER_PRESENT`）刷新 |
| 权限 | `POST_NOTIFICATIONS`、`USE_EXACT_ALARM`、`SCHEDULE_EXACT_ALARM`（≤32）、`RECEIVE_BOOT_COMPLETED` |

## 7. 构建期间发现并修复的问题

| 问题 | 现象 | 处理 |
|---|---|---|
| Kotlin 插件缺失 | 5 个 `.kt` 小组件文件被 Gradle 静默忽略，无任何报错，dex 中查不到类 | 根 `build.gradle` 加入 `kotlin-gradle-plugin`，`app/build.gradle` 应用 `org.jetbrains.kotlin.android` |
| JVM 目标不一致 | `compileDebugJavaWithJavac (21)` 与 `compileDebugKotlin (17)` 冲突 | Capacitor 生成的 `capacitor.build.gradle` 将 Java 兼容级别设为 21，Kotlin `jvmTarget` 对齐为 21 |
| 路径基准不同 | `tauri build` 找不到前端产物：`frontendDist` 相对 `src-tauri` 解析，`beforeBuildCommand` 相对 `apps/desktop` | `frontendDist` 改为 `../../web/dist` |
| cargo 不在 PATH | Tauri CLI 报 `cargo metadata: program not found` | 构建前将 `%USERPROFILE%\.cargo\bin` 加入 PATH |
| Gradle 发行包超时 | `services.gradle.org` 拉取 0 字节 | 改走 `mirrors.cloud.tencent.com`，`networkTimeout` 提到 60000 |
| JDK 21 工具链缺失 | 插件要求 `languageVersion=21`，本机只有 17 与 8 | 免安装安装 Microsoft OpenJDK 21 到 `E:\work\dsh\jdk21`，并登记 `org.gradle.java.installations.paths` |
| Gradle 管道被截断 | `Select-Object -First` 提前结束管道导致构建进程被杀 | 验证阶段不再用管道截断构建输出 |
