# 界面重做记录

日期：2026-10-10

## 1. 技术栈

| 项 | 选型 |
|---|---|
| 样式 | Tailwind CSS v4（`@tailwindcss/vite`，CSS-first `@theme`） |
| 无障碍原语 | Radix UI（dialog、tabs、select、switch、checkbox、dropdown、popover、tooltip、slot、scroll-area、label、separator、radio-group、collapsible） |
| 组件组织 | shadcn 风格自持组件（`apps/web/src/components/ui`） |
| 变体与合并 | class-variance-authority、clsx、tailwind-merge |
| 图标 | lucide-react |
| 抽屉 | vaul |
| 提示 | sonner |

原手写样式（252 行 `styles.css`）已删除，迁移期临时保留的 `styles/legacy.css` 在页面全部替换后删除。

## 2. 设计令牌

| 产物 | 位置 |
|---|---|
| 令牌源 | `apps/web/src/design/tokens.ts` |
| 对比度算法 | `apps/web/src/design/contrast.ts` |
| 运行时变量 | `--dt-*`，由 `applyTheme` 写入根元素 |
| Tailwind 映射 | `styles.css` 的 `@theme inline` |
| JSON 导出 | `docs/design-tokens.json` |

语义拆分：原色用于填充与色块，文字、图标与焦点环一律使用 `*Strong` 派生变体（向黑或向白混色至达标）。

## 3. 实测结论

| 结论 | 数据 |
|---|---|
| `text` / `muted` 在四套主题的浅深模式下均达标 | 最低 4.98:1 |
| light 模式下 `primary` 不能作文字色 | vivid 2.66、muted 2.78 |
| light 模式下 `accent` 不能作文字色 | fresh 2.75、mono 2.98、muted 2.74 |
| 课程色块内不能使用 `muted` | 18 处低于 4.5:1，最低 4.24 |
| 课程色块内 `text` 与 `text@80%` 达标 | 全部通过 |

## 4. 组件库

| 组件 | 说明 |
|---|---|
| Button / Card / Input / Field / Label / Textarea | 基础控件，尺寸含 44px 触控下限 |
| Select / Switch / Checkbox | Radix 原语封装 |
| Dialog / Sheet | 桌面居中弹窗；移动底部弹窗与平板右侧抽屉共用内容 |
| Tabs / EmptyState / Toaster | 视图切换、空状态、应用内提示 |
| CourseCard / Countdown / NowIndicator | 课程块（左色条 + 色调底）、倒计时、当前时间指示线 |

## 5. 布局与导航

| 断点 | 布局 |
|---|---|
| < 768px | 底部导航（课表/日程/导入/我的）+ 悬浮添加 + 底部弹窗 |
| 768–1024px | 底部导航 + 表单单列、列表双列 + 右侧抽屉 |
| > 1024px | 左侧边栏 + 顶部工具栏 + 主内容 + 右侧详情面板 |

工具栏：学期选择、周次前后切换、今天、周/日切换、搜索、添加课程。
快捷键：`←` / `→` 切周、`T` 回今天、`/` 搜索。

## 6. 页面

| 页面 | 内容 |
|---|---|
| 周视图 | 时间轴（节次 + 起止时间）、课程块、当前时间指示线、点击详情、左右滑动切周、拖拽调课 |
| 今日视图 | 下一节高亮与倒计时、当日课程列表、空状态 |

| 搜索 | 课程、教师、地点、周次与日程，150ms 防抖，回车取首条 |

## 7. 数据层与原生

| 项 | 内容 |
|---|---|
| 检索 | `packages/core/src/search.ts`，前缀命中权重高于中间命中 |
| 拖拽调课 | 拖动后弹窗选「仅本周」（`createReschedule`）或「从本周起每周」（`updateSchedule`） |
| 正方教务 | `packages/core/src/import/jwglxt.ts`：地址归一化、登录页字段、公钥、RSA 加密口令（BigInt 模幂）、课表页解析与连堂合并 |
| 小组件 | 四个（2×2 下一节课、4×2 今日课表、4×4 一周概览、2×2 考试倒计时），背景支持浅色/深色/透明 |

## 8. 未验证项

| 项 | 原因 |
|---|---|
| 正方教务真实登录 | 需要目标校 URL 与账号；解析与加密仅以固定样例与 RSA 向量验证 |
| 小组件真机显示 | 需要设备或模拟器；已通过 APK 内 dex 与清单声明校验 |
| 拖拽与滑动手感 | 需要人工在浏览器与设备上确认 |

界面渲染由 `tools/verify/smoke-ui.mjs` 覆盖：jsdom 环境渲染 `App`，验证空库引导页、课表渲染课程与周次、当前时间指示线、切日程页、切设置页、搜索弹窗共 8 项。
