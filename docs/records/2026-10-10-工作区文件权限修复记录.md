# 工作区文件权限修复记录

日期：2026-10-10 ｜ 对象：`E:\work\dsh\dawn-tick` ｜ 状态：已修复

## 1. 现象

会话启动时所有命令失败，包括只读命令：

```
Error: SetNamedSecurityInfoW failed (Win32 5): grantWrite(E:\work\dsh\dawn-tick)
fatal: not a git repository (or any of the parent directories): .git
```

## 2. 原因

`E:\work\dsh\dawn-tick` 缺少「修改所有者」权限，且无法从上级目录 `E:\work\dsh` 继承（`E:\` 的所有者为系统账户，当前用户无修改权限）。DSH 无法为该目录授予工作区写权限。

## 3. 处理

对 `E:\work\dsh\dawn-tick` 追加一条「当前登录用户完全控制」权限项。未删除其他权限项，未改动所有者，未改动文件内容。

修复前后的权限读数：

| 项 | 修复前 | 修复后 |
|---|---|---|
| WRITE_DAC | True | True |
| WRITE_OWNER | False | True |

修复后原只读命令执行成功，git 仓库在 `E:\work\dsh\dawn-tick` 初始化成功。
