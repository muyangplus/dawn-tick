## 3. 覆盖范围

| 维度 | 覆盖内容 |
|---|---|
| 建表 | 8 张表 DDL、CHECK、外键、部分唯一索引 |
| 周次 | 连续（1–16）、双周（2–16）、碎片（1/3/5/7）、越界（第 17 周）、位图编码 |
| 同步预留 | `rev` / `dirty` 默认值与写入；`app_meta` 不含同步字段 |
| events 七种 type | 七种 type 写入；12 项条件 CHECK 拦截 |
| 子任务 | `parent_id` 写入、自引用拦截、父任务级联删除 |
| 引用完整性 | 课程→排课级联；排课→调课级联；父任务→子任务级联 |
| 部分唯一索引 | 每用户一个当前学期；同学期同节次唯一；同一天一条假期/调休记录 |
| 来源优先级 | 教务覆盖内置；内置不覆盖手动 |
| 软删除 | 同一节次可重建（不与部分唯一索引冲突） |
| 数据校验 | 节次区间、星期范围、位图为空、节次上限、学分负数、提前分钟、贪睡分钟 |
