## 5. 环境与坑

| 项 | 内容 |
|---|---|
| MSVC D8050 | VS 18 BuildTools 的 MSVC 14.51 编译 `libsqlite3-sys` 自带 SQLite 时，`/Z7` 触发 `cl.exe D8050`；在 `Cargo.toml` 设 `[profile.dev] debug = 0` 与 `[profile.test] debug = 0` 后通过 |
| cargo 读取已关闭的系统代理 | Windows 注册表 `ProxyServer=127.0.0.1:7897` 即使 `ProxyEnable=0` 仍被 cargo 使用；以 `NO_PROXY` 限定镜像域名解决 |
| 镜像源 | rustup → TUNA、crates.io → USTC、npm → npmmirror，见 `tools/setup/setup-mirrors.ps1` |
