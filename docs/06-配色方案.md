## 通用规则

| 项 | 规则 |
|---|---|
| 课程色分配 | 按课程创建顺序取色板下一色，第 13 门起循环 |
| 深色下可读性 | 课程色用于左侧色条与文字时，深色主题取同名色板的深色列；文字对比度不低于 4.5:1 |
| 主题切换 | 跟随系统 + 手动切换（D45） |
| 存储 | `app_meta.theme`，取值 `light` / `dark` / `system`；主题名单独存 `app_meta.theme_preset` |

## 语义令牌

原色用于填充与大面积色块；作为文字或图标时一律使用 `*Strong` 派生变体，派生方式为向黑（浅底）或向白（深底）混色至达标。

| 令牌 | 来源 | 用途 |
|---|---|---|
| `bg` / `surface` / `surfaceMuted` | 上表原值 | 页面底色、卡片、次级面板 |
| `text` / `muted` | 上表原值 | 正文与次要文字 |
| `border` | 上表原值 | 分隔线（装饰） |
| `borderStrong` | 由 `border` 派生 | 交互轮廓与输入框边框，≥ 3:1 |
| `primary` / `accent` | 上表原值 | 填充按钮、色条、大面积色块 |
| `onPrimary` | 由 `primary` 择优（黑或白） | 填充上的文字，≥ 4.5:1 |
| `primaryStrong` / `accentStrong` | 由原色派生 | 作为文字、图标、焦点环，≥ 4.5:1 |
| `success` / `warning` / `danger` / `info` | 上表原值 | 状态填充 |
| `successStrong` / `warningStrong` / `dangerStrong` / `infoStrong` | 由原色派生 | 状态文字，≥ 4.5:1 |
| `course-N` | 各预设 12 色 | 课程标识色 |
| `course-N-tint` | `mix(surface, course-N, 0.18)` | 课程块底色 |
| `overlay` | `rgba(0,0,0,0.36)` | 弹窗遮罩 |

## 无障碍约束

| 约束 | 值 |
|---|---|
| 正文、次要文字与背景 | ≥ 4.5:1 |
| 轮廓、焦点环、图标 | ≥ 3:1 |
| 课程块内文字 | ≥ 4.5:1 |
| 触控区域 | ≥ 44×44px |
| 颜色不作为唯一区分 | 课程块同时带文字与左侧色条 |

## 静态令牌

| 类别 | 值 |
|---|---|
| 间距 | 4 / 8 / 12 / 16 / 24 / 32 px |
| 圆角 | 8 / 12 / 16 px，胶囊 9999px |
| 字号 | 12 / 14 / 16 / 20 / 24 / 32 px |
| 阴影 | sm / md / lg 三档，仅用于悬浮卡片与弹窗 |
