## 通用规则

| 项 | 规则 |
|---|---|
| 课程色分配 | 按课程创建顺序取色板下一色，第 13 门起循环 |
| 深色下可读性 | 课程色用于左侧色条与文字时，深色主题取同名色板的深色列；文字对比度不低于 4.5:1 |
| 主题切换 | 跟随系统 + 手动切换（D45） |
| 存储 | `app_meta.theme`，取值 `light` / `dark` / `system`；主题名单独存 `app_meta.theme_preset` |
