# 晓刻 DawnTick — 范围与决策

最后更新：2026-10-10

## 1. 产品定位

**晓刻 DawnTick**：面向学生与轻量日程用户的课表 / 日程提醒工具。

- 核心价值：课表导入一次，多端同步，课前准时提醒，桌面小组件随时看。
- 目标用户：大学生、中学生、研究生、教师。
- 核心场景：看课表、导课表、被提醒、看小组件。

## 3. 架构原则

1. 离线优先：本地 SQLite 是真相来源，联网后按 `pull → push → pull` 同步。
2. 一套 DDL 跑三端：Web(SQLite-WASM+OPFS) / Windows(tauri-plugin-sql) / Android(Capacitor SQLite)，建表 SQL 只用标准 SQLite 语法。
3. 轻量化：不引重量级依赖，能自写就自写。
4. 业务代码不直连数据库：统一走数据访问层。
