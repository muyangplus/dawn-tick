## 1. 产品定位

**晓刻**：面向学生与轻量日程用户的课表 / 日程提醒工具。

- 核心价值：**课表导入一次，多端同步，课前准时提醒，桌面小组件随时看。**
- 目标用户：大学生、中学生、研究生、教师。
- 核心场景：看课表、导课表、被提醒、看小组件。

## 2. 核心功能范围

| 模块 | 功能 |
|---|---|
| 课表 | 周视图、今日视图、课程详情、颜色标记 |
| 导入 | 教务系统 HTML、CSV/Excel、ICS、手动添加 |
| 提醒 | 课前 5/10/15/30 分钟提醒、自定义、节假日跳过 |
| 小组件 | 下一节课、今日课表、一周概览、考试倒计时 |
| 日程 | 考试、待办、调课、临时日程 |
| 多端 | Web、Windows、Android |
| 同步 | 离线优先，多端自动同步 |

支持便捷调休 / 调日程。

## 3. 架构原则

**离线优先**：本地 SQLite 是真相来源，联网后按 `pull → push → pull` 同步。
（本期不实现服务端，但数据模型与代码结构必须为其预留。）
