# 晓刻 — 范围与决策

最后更新：2026-10-10

## 1. 产品定位

**晓刻**：面向学生与轻量日程用户的课表 / 日程提醒工具。

- 核心价值：课表导入一次，多端同步，课前准时提醒，桌面小组件随时看。
- 目标用户：大学生、中学生、研究生、教师。
- 核心场景：看课表、导课表、被提醒、看小组件。

## 3. 架构原则

1. 离线优先：本地 SQLite 是真相来源，联网后按 `pull → push → pull` 同步。
2. 一套 DDL 跑三端：Web(SQLite-WASM+OPFS) / Windows(tauri-plugin-sql) / Android(Capacitor SQLite)，建表 SQL 只用标准 SQLite 语法。
3. 轻量化：不引重量级依赖，能自写就自写。
4. 业务代码不直连数据库：统一走数据访问层。

| D20 | 周次存储编码 | 位图整数 `weeks_mask` |
| D22 | 节假日来源优先级 | 手动 > 教务校历 > 内置；每天仅一条记录，优先级在写入时决定 |
| D23 | 同步预留字段 | 本期建立 `rev` / `dirty` |
| D34 | 开学日期语义 | 开学日期所在那一周为第 1 周，周一起算；内置日历只用于判断上课/调休 |
| D35 | 上下午分区 | `time_slots.section` 按时间自动推断，允许手动覆盖 |
| D36 | 待办字段 | `events` 新增 `priority`、`due_at`；子任务用 `parent_id` 自关联 |
| D37 | 考试字段 | `events` 新增 `subject`、`seat_no`；考场复用 `location` |
| D38 | 提醒字段 | `reminders` 新增 `sound`、`vibrate`、`dnd`、`snooze_minutes` |
| D52 | 时刻存储 | 时刻存 UTC epoch 毫秒；日期存 `'YYYY-MM-DD'`；课表墙钟存 `'HH:MM'` 并配 `semesters.time_zone` |
| D53 | 显示时区 | 默认 `Asia/Shanghai`；可开启跟随设备时区；设置里可手动指定 |
| D54 | 建表 SQL | `packages/core/src/schema/001_init.sql` 为唯一事实来源，文档不再重复 DDL |
| D55 | 迁移机制 | 编号 `.sql` 文件，`migrate.ts` 按 id 升序应用，版本号记于 `app_meta.schema_version` |
| D39 | 备份格式 | JSON 全量备份导出/导入 |
| D40 | 展开结果 | 现算，不落库 |
| D41 | 数据访问层 | 手写 SQL + TypeScript 类型定义，不引 ORM |
