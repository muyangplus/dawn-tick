# 01 产品与功能

离线优先的课表与日程提醒应用，同一套领域代码与界面代码分别装进浏览器、Windows 桌面与 Android 应用。

## 1. 平台与产物

| 平台 | 形态 | 本地存储 | 产物 |
|---|---|---|---|
| Web | 浏览器应用 | IndexedDB | `apps/web/dist` |
| Windows | Tauri 2 桌面应用（悬浮窗 + 托盘） | SQLite | NSIS 安装包、免安装 zip |
| Android | Capacitor 应用（2×2 / 4×2 / 4×4 主屏小组件） | SQLite | APK |

| 项 | 内容 |
|---|---|
| 领域逻辑 | TypeScript，`packages/core` |
| 界面 | React 19 + Vite 8 + Tailwind CSS v4 + Radix 原语 + lucide 图标 |
| 桌面壳 | Tauri 2（Rust）+ `tauri-plugin-sql` |
| 移动壳 | Capacitor + Kotlin 小组件 |
| 测试 | `node --test`、内存存储、`node:sqlite` 与 Python 跨引擎校验 |

## 2. 功能清单

### 2.1 课表

| 能力 | 行为 |
|---|---|
| 学期与节次 | 每学期一套节次表，逐节起止时间与显示名可选 am / pm / night |
| 周视图 | 1–7 天任意天数，窄屏按列宽压缩、不横向滚动 |
| 节次轴 | 始终显示每节的起止时间 |
| 时间指示 | 时间轴与当前时间指示线 |
| 今日视图 | 下一节高亮与倒计时；正在上的课标「进行中」并显示剩余时间 |
| 格子内容 | 课程缩写、教师、地点、颜色标记 |
| 周次语义 | 查看窗口外的周次按设置虚线显示 |
| 课程管理 | 课程与排课的新增、编辑、删除 |
| 复制课程 | 可选只复制课程信息，或连排课一起复制 |
| 拖拽调课 | 长按后拖动改期；停课的课次不参与拖动 |
| 调课与停课 | 原位置标「已调课」，落点标「调课」，停课灰显 |
| 假期与调课 | 设为假日、连续假期（最多 60 天）、停课、顺延 |
| 实验条目 | 按周次位图落格并标「实验」，不参与拖动 |
| 自定义时间 | 条目与排课都可给真实起止时间，按真实时间定位而非节次 |
| 检索 | 课程、教师、地点、周次与日程全文搜索，`/` 唤起 |

### 2.2 日程

| 能力 | 行为 |
|---|---|
| 入口 | 一个「加待办」，类型可选日程 / 作业 / 考试 / 实验 |
| 类型默认 | 作业与考试默认开启倒计时，作业默认需要手动确认完成，实验默认显示在课表上 |
| 逐条开关 | 开启倒计时、需要手动确认完成、自定义时间、显示在课表上 |
| 倒计时卡片 | 按时间排序，条目可单击进详情，也可直接勾完成 |
| 详情编辑 | 倒计时卡片与时间线条目都能单击进详情编辑，已完成的同样可以 |
| 待办列表 | 分组与勾选，排序可选按开始时间或按类型 |

### 2.3 导入

| 能力 | 行为 |
|---|---|
| ICS | 导入与导出，周次语义往返不变 |
| CSV / Excel | 二维矩阵解析导入 |
| 内置入口 | 内置高校与教务入口列表 |
| 内嵌教务窗口 | Windows 独立窗口、Android 应用内 WebView |
| 网页识别 | 通用网页课表识别，含手动校正字段映射 |
| 手动添加 | 逐条手动录入课程与排课 |
| 入口位置 | 导入在设置页内，不单独占导航 |
| 明文 http | Android 允许明文 http，外部链接交给系统浏览器打开 |

### 2.4 提醒

| 能力 | 行为 |
|---|---|
| 提前量 | 课前 5 / 10 / 15 / 30 分钟与自定义 |
| 默认规则 | 未单独设置的课程按「课前提醒默认提前分钟数」提醒 |
| 放假跳过 | 放假日与调休日不误提醒 |
| 贪睡 | 提醒可贪睡，分钟数可设 |
| 勿扰分级 | 不穿透 / 仅课前提醒穿透 / 全部穿透三档 |
| 声音与震动 | 逐条提醒开关 |
| 通知权限 | Android 启动时申请通知权限 |
| 精确闹钟 | 课前提醒开着而精确闹钟未授权时跳一次系统设置页 |
| 电池优化 | 设置页给出电池优化白名单入口 |

### 2.5 数据

| 能力 | 行为 |
|---|---|
| 备份格式 | JSON 文件、Base64 文本、整包 zip |
| 导出选项 | 按模块勾选；导出时选保存位置，默认文件名全为英文 |
| 导入入口 | 一个「导入配置」，可选文件也可粘贴文本 |
| 冲突策略 | 跳过已有数据 / 覆盖已有数据 / 清空所选模块后导入 / 按修改时间合并 |
| 快照备份 | 自动备份支持启动时与每天各一次，保留份数可设 |
| 快照管理 | 设置页可查看、恢复与删除快照 |
| 跨设备迁移 | 导出配置与导入配置，整包 zip 可选带预设快照与日志 |
| 同步协议 | pull → push → pull |

### 2.6 组件

| 形态 | 内容 |
|---|---|
| Windows 悬浮窗 | 四种样式；上课中显示剩余时间 |
| 悬浮窗空态 | 当天没课或课上完时，可按「空日程提示明日预告」显示明日课程预告 |
| Android 2×2 下一节课 | 原生 Kotlin 小组件 |
| Android 4×2 今日课表 | 原生 Kotlin 小组件 |
| Android 4×4 一周概览 | 原生 Kotlin 小组件 |
| Android 2×2 考试倒计时 | 原生 Kotlin 小组件 |
| 添加引导 | 设置页每个尺寸一个「添加到桌面」按钮，可一键请求添加 |
| 刷新 | 数据变更即时刷新 + 30 分钟周期 + 解锁屏幕 |

### 2.7 更新

| 能力 | 行为 |
|---|---|
| 应用更新取源 | 首选 `api.github.com` 发布接口，回退发布内 `version.json` |
| 预设取源 | 首选 `raw.githubusercontent.com`，回退 `api.github.com` contents 接口 |
| 检查时机 | 「自动检查版本更新」默认开启，启动后自动查一次 |
| 结果展示 | 发现新版本时弹窗显示版本、渠道与发布说明 |
| 预设更新 | 设置页「检查预设更新」，校验 sha256 后写入本地缓存 |
| 生效时机 | 预设下载成功后提示「下次启动生效」，运行时不替换当前预设 |
| 关于区块 | 展示预设版本（内置 / 已更新）与预设更新按钮 |
| 渠道提示 | 开发版与测试版各一条首次提示，每条只弹一次，新增提示对老用户也弹 |

### 2.8 主题

| 能力 | 行为 |
|---|---|
| 配色 | 四套配色 × 深浅模式 |
| 深色模式 | 手动切换或跟随系统 |
| 设计令牌 | 令牌导出与对比度校验 |
| 小组件背景 | 浅色 / 深色 / 透明，同时作用于悬浮窗与 Android 小组件 |
| 时区 | 选择列表，默认上海；首次启动按系统时区对齐一次 |
| 界面动效 | 跟随系统 / 始终播放 / 关闭动效 |
| 加载状态 | 异步按钮自动禁用并转圈；慢操作盖半透明蒙版，重复点击被忽略 |

## 4. 术语表

| 术语 | 含义 |
|---|---|
| 学期 | 一条 `semesters` 记录；含开学日期、总周数与学期时区，每用户只有一条为当前学期 |
| 节次 | 一天内的上课序号，1 起算；起止时间来自 `time_slots`，一天实际节次数由该表行数决定 |
| 周次 | 第 1 周为开学日期所在那一周，周一起算；上限 30 周 |
| 条目 | 课表之外的一条记录：日程、作业、考试、实验，或调课、放假、调休、明确上课日 |
| 课表窗口 | 周视图当前显示的连续日期区间，长度等于「周视图天数」，起点默认今天 |
| 假期与调课 | 按「学期 + 日期」判定的当天性质：放假、调休补课、明确上课日，或对某次排课的停课、改期、换教室 |
