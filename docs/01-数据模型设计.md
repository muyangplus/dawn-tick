# 晓刻 DawnTick — 数据模型设计

最后更新：2026-10-10
建表 SQL 唯一事实来源：`packages/core/src/schema/001_init.sql`
校验：Node 33 项、Web WASM 5 项、Windows sqlx 6 项、Android 引擎 6 项、Python 跨引擎 30 项，全部通过（见 `records/M1-三端建库校验记录.md`）

## 1. 通用约定

| 约定 | 取值 |
|---|---|
| 主键 | `id TEXT PRIMARY KEY`，UUIDv7 |
| 时刻 | INTEGER，UTC epoch 毫秒 |
| 日期 | TEXT，`YYYY-MM-DD`，不存时区 |
| 课表墙钟 | TEXT，`HH:MM`，配合 `semesters.time_zone` 解释 |
| 时区 | IANA 名称，默认 `Asia/Shanghai` |
| 同步预留 | `rev INTEGER NOT NULL DEFAULT 0`、`dirty INTEGER NOT NULL DEFAULT 0` |
| 软删除 | `deleted_at INTEGER NULL`（UTC 毫秒），查询过滤 |
| 布尔值 | INTEGER 0/1 |
| 枚举 | TEXT + `CHECK(...)` |
| 外键 | 每次连接执行 `PRAGMA foreign_keys = ON` |
| 周次起算 | 第 N 周 = 位图第 (N-1) 位；全项目 1 起算 |
| 第 1 周 | 开学日期所在那一周，周一起算 |

## 2. 时间语义

| 数据 | 存储 | 说明 |
|---|---|---|
| 时刻（考试起止、截止、提醒触发、created_at、updated_at） | UTC epoch 毫秒 | 显示时按设置时区换算 |
| 日期（开学日期、假期日、调课原上课日、调课新日期） | `'YYYY-MM-DD'` | 日期不是时刻，不做时区换算 |
| 课表墙钟（节次起止） | `'HH:MM'` | 与 `semesters.time_zone` 组合后得到时刻 |
| 周次、节次编号 | INTEGER | 1 起算 |

显示时区取值顺序：

1. `app_meta.auto_time_zone = '1'` 时用设备时区（非法则回退）；
2. 否则用 `app_meta.time_zone`（非法则回退）；
3. 回退值为 `Asia/Shanghai`。

实现：`packages/core/src/time.ts` 的 `resolveTimeZone`、`dateWallClockToEpoch`、`formatDateTime`。

## 3. 表

字段与约束以 `packages/core/src/schema/001_init.sql` 为准。以下为字段语义。

### 3.1 users
| 字段 | 类型 | 说明 |
|---|---|---|
| id | TEXT | 主键 |
| nickname | TEXT | 昵称，默认 `我` |
| created_at / updated_at / deleted_at / rev / dirty | — | 见第 1 节 |

### 3.2 semesters
| 字段 | 类型 | 说明 |
|---|---|---|
| id | TEXT | 主键 |
| user_id | TEXT | 外键 users，级联删除 |
| name | TEXT | 学期名 |
| start_date | TEXT | 开学日期 |
| total_weeks | INTEGER | 总周数，1..30 |
| time_zone | TEXT | 学期时区，默认 `Asia/Shanghai` |
| is_active | INTEGER | 每用户仅一条为 1（部分唯一索引 `ux_semesters_active`） |

### 3.3 time_slots
| 字段 | 类型 | 说明 |
|---|---|---|
| id | TEXT | 主键 |
| semester_id | TEXT | 外键 semesters，级联删除 |
| period_no | INTEGER | 第几节，1..40，每学期唯一（`ux_time_slots`） |
| start_time / end_time | TEXT | `HH:MM` 墙钟 |
| label | TEXT | 显示名，如 `第1-2节` |
| section | TEXT | `am` / `pm` / `night`，按 `start_time` 推断，可覆盖 |

一天实际节次数由本表行数决定。

### 3.4 courses
| 字段 | 类型 | 说明 |
|---|---|---|
| id | TEXT | 主键 |
| semester_id | TEXT | 外键 semesters，级联删除 |
| name | TEXT | 课程名 |
| short_name | TEXT | 课表格子内缩写 |
| teacher | TEXT | 教师 |
| location | TEXT | 默认地点，被排课行覆盖 |
| color | TEXT | 十六进制色值 |
| credits | REAL | 学分，非负 |
| note | TEXT | 备注 |

### 3.5 course_schedules
| 字段 | 类型 | 说明 |
|---|---|---|
| id | TEXT | 主键 |
| course_id | TEXT | 外键 courses，级联删除 |
| day_of_week | INTEGER | 1=周一 … 7=周日 |
| period_start / period_end | INTEGER | 起止节次，`period_end >= period_start` |
| weeks_mask | INTEGER | 周次位图，> 0 |
| weeks_raw | TEXT | 教务原文，如 `1-16周(单)` |
| room | TEXT | 覆盖 courses.location |

位图取值：

| 周次集合 | `weeks_mask` |
|---|---|
| 第 1–16 周 | 65535 |
| 双周 2–16 | 43690 |
| 仅第 1/3/5/7 周 | 85 |

查询条件：`(weeks_mask >> (:week - 1)) & 1 = 1`
读写实现：`packages/core/src/weeks.ts` 的 `setWeek` / `hasWeek`。

### 3.6 reminders
| 字段 | 类型 | 说明 |
|---|---|---|
| id | TEXT | 主键 |
| user_id | TEXT | 外键 users，级联删除 |
| target_type | TEXT | `course` / `schedule` / `event` |
| target_id | TEXT | 目标主键，无外键 |
| advance_minutes | INTEGER | 提前分钟，0..1440，默认 10 |
| enabled | INTEGER | 开关，默认 1 |
| skip_holidays | INTEGER | 节假日跳过，默认 1 |
| sound / vibrate | INTEGER | 默认 1 |
| dnd | INTEGER | 勿扰三档：0 不穿透 / 1 仅课前提醒穿透 / 2 全部穿透 |
| snooze_minutes | INTEGER | 贪睡分钟，1..120，可空 |

### 3.7 events
| 字段 | 类型 | 说明 |
|---|---|---|
| id | TEXT | 主键 |
| user_id | TEXT | 外键 users，级联删除 |
| semester_id | TEXT | 外键 semesters，删除置空 |
| parent_id | TEXT | 自关联 events，级联删除；指向自身被拒绝 |
| type | TEXT | 见下表 |
| title | TEXT | 标题 |
| on_date | TEXT | 针对日期，`YYYY-MM-DD` |
| start_at / end_at / due_at | INTEGER | UTC 毫秒 |
| all_day | INTEGER | 全天 |
| location | TEXT | 地点；考试时作考场 |
| note | TEXT | 备注 |
| done | INTEGER | 待办完成 |
| priority | INTEGER | 待办优先级 1..3 |
| subject / seat_no | TEXT | 考试科目、座位号 |
| ref_schedule_id | TEXT | 外键 course_schedules，级联删除 |
| action | TEXT | `move` / `cancel` / `room_change` / `add` |
| new_date | TEXT | 调课新日期 |
| new_period_start / new_period_end | INTEGER | 调课新节次 |
| new_room | TEXT | 调课新教室 |
| as_day_of_week | INTEGER | 补课按星期几上课 |
| source | TEXT | `builtin` / `manual` / `from_school` |

type 与专用字段：

| type | 含义 | 专用字段 | 约束 |
|---|---|---|---|
| exam | 考试 | subject、seat_no、location、start_at | subject、seat_no 仅本类型可有 |
| todo | 待办 | priority、due_at、done、parent_id | priority、due_at 仅本类型可有 |
| temp | 临时日程 | start_at、end_at、all_day | — |
| reschedule | 调课 | ref_schedule_id、action、new_date、new_period_*、new_room、on_date | ref_schedule_id 与 action 必填；action=move 时 new_date 必填 |
| holiday | 放假 | on_date、source | on_date 必填 |
| makeup | 调休补课 | on_date、as_day_of_week、source | on_date、as_day_of_week 必填 |
| workday | 明确上课日 | on_date、source | on_date 必填 |

节假日来源优先级：`manual` > `from_school` > `builtin`。
同一 (semester_id, on_date) 仅允许一条假期/调休/上课日记录（`ux_events_day_kind`），优先级在写入时决定：

| 情形 | 动作 |
|---|---|
| 该日期无记录 | 插入 |
| 已有记录，新来源优先级更高 | 覆盖 |
| 已有记录，新来源优先级更低或相同 | 跳过 |

### 3.8 app_meta
| 字段 | 类型 | 说明 |
|---|---|---|
| key | TEXT | 主键 |
| value | TEXT | 值 |

不同步，无 `rev` / `dirty`。键：`schema_version`、`device_id`、`sync_cursor`、`time_zone`、`auto_time_zone`、`view_days`、`theme`。

## 4. 关系

```
users ─1:N─ semesters ─1:N─┬─ courses ─1:N─ course_schedules ─┐
                           └─ time_slots                       │
users ─1:N─ events ─────────(ref_schedule_id)──────────────────┘
                  └─(parent_id 自关联)
users ─1:N─ reminders ─(弱引用)─> courses / course_schedules / events
```

## 6. 展开（expand）

实现：`packages/core/src/expand.ts`。

```
expand(input: ExpandInput) -> Occurrence[]

Occurrence = {
  date, semesterId, scheduleId, courseId, courseName, shortName, color,
  periodStart, periodEnd, startAt, endAt, room, cancelled
}
```

输入：学期（`start_date`、`total_weeks`、`time_zone`）、课程、排课、节次、日期判定、调课记录、日期区间。

处理顺序：

| 步骤 | 规则 |
|---|---|
| 1 | 日期判定为 `holiday` 时当天不产生课次 |
| 2 | 日期判定为 `makeup` 时用 `as_day_of_week` 取代自然星期；`workday` 用自然星期 |
| 3 | 周次 = 该日期所属周次；早于第 1 周或超出 `total_weeks` 时跳过 |
| 4 | 排课 `day_of_week` 与有效星期一致且 `weeks_mask` 含该周次时产生课次 |
| 5 | `reschedule` + `cancel` 置 `cancelled`；`move` 改日期与节次；`room_change` 改教室 |
| 6 | 教室取 `new_room` > `schedule.room` > `course.location` |

结果按 `startAt` 排序，不落库。课表渲染、提醒调度、小组件共用。
`nextOccurrence(occurrences, nowMs)` 返回 `nowMs` 之后最近一次未取消的课次。

## 7. 存储抽象层

业务逻辑不依赖 SQL，只依赖文档集合接口。

| 接口 | 位置 | 内容 |
|---|---|---|
| `Storage` | `packages/core/src/storage.ts` | `collection<T>(name)`、`readMeta`、`writeMeta`、`close` |
| `Collection<T>` | 同上 | `get`、`getAll`、`put`、`putMany`、`delete`、`clear` |
| 共享业务逻辑 | `packages/core/src/repository.ts` | 周视图、放假调休判定与写入、展开输入组装 |

各端实现：

| 端 | 实现 | 主键 |
|---|---|---|
| Web | IndexedDB（`apps/web/src/db/idb-storage.ts`，`idb` 封装） | 与 SQLite 端同名同主键 |
| Windows | SQLite（Tauri 2 + `tauri-plugin-sql`） | 同上 |
| Android | SQLite（Capacitor + `@capacitor-community/sqlite`） | 同上 |
| 测试与脚本 | `MemoryStorage`、`sqliteStorage`（`node:sqlite`） | 同上 |

约束：

1. 集合清单与主键由 `STORE_NAMES` / `STORE_KEYS` 单点定义，各端据此建存储。
2. 业务代码只经 `Storage` 访问数据，不直接接触具体驱动。
3. `001_init.sql` 是 **SQLite 端的物理结构**；Web 端的结构由同一份集合清单与实体类型决定。
4. SQLite 端每次建立连接执行 `PRAGMA foreign_keys = ON`。
5. 迁移为编号 `.sql` 文件，`packages/core/src/migrate.ts` 按 id 升序应用，版本号记于 `app_meta.schema_version`。

同步：

| 接口 | 位置 | 内容 |
|---|---|---|
| `RemoteStore` | `packages/core/src/sync.ts` | `push`、`pull` |
| `syncAll` | 同上 | pull → push → pull |
| `MemoryRemote` | 同上 | 本机可跑的远端实现 |

同步单位为文档整体，依据 `rev` 与 `updated_at` 判定，冲突记入 `ConflictRecord`。

## 8. 约束与已知限制

| # | 内容 |
|---|---|
| L1 | `setWeek` 限制周次 ∈ [1, 30]；位图在数据库层无上界校验 |
| L2 | `reminders.target_id` 无外键，删除目标须由数据访问层清理 |
| L3 | 单表承载 7 种 `type`，多数行仅使用部分列 |
| L4 | 软删除与部分唯一索引并存，恢复软删除数据时可能撞唯一索引 |
| L5 | SQLite 端（Windows / Android）的引擎版本与编译选项不同，现有校验覆盖 Node 内置 SQLite、Python SQLite 与 Android 平台工具自带 SQLite |
| L6 | `parent_id` 的父记录 `type` 必须为 `todo`，该规则无法用 `CHECK` 表达，由数据访问层保证 |
| L7 | `total_weeks` 与位图上界均为 30 |
| L8 | 调课 `move` 的目标日期若落在查询区间之外，该次课次不出现在结果中 |
| L9 | **IndexedDB 无数据库约束**：`CHECK`、外键、唯一索引只在 SQLite 端生效，同一份非法数据在 Web 端不会被拦截，校验责任在共享数据访问层 |
| L10 | 同步冲突解决当前为「远端版本更高则远端胜、同版本取更新时间较新者」，并记入冲突列表；字段级对比与用户选择属 M9 |
| L11 | `MemoryRemote` 仅用于本机验证，进程退出即丢失 |
