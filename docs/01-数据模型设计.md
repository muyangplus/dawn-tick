# 晓刻 — 数据模型设计

最后更新：2026-10-10 ｜ 校验状态：48 项全通过（`tools/schema-check/validate_schema.py`）

## 1. 通用约定

| 约定 | 取值 |
|---|---|
| 主键 | `id TEXT PRIMARY KEY`，UUIDv7 |
| 时间戳 | `created_at` / `updated_at`：INTEGER，Unix 毫秒（UTC） |
| 同步预留 | `rev INTEGER NOT NULL DEFAULT 0`、`dirty INTEGER NOT NULL DEFAULT 0` |
| 业务日期 | `TEXT`，`YYYY-MM-DD`（本地墙钟） |
| 业务时刻 | `TEXT`，`YYYY-MM-DDTHH:MM:SS+08:00`（本地墙钟 + 时区） |
| 软删除 | `deleted_at INTEGER NULL`，查询过滤 `deleted_at IS NULL` |
| 布尔值 | INTEGER 0/1 |
| 枚举 | TEXT + `CHECK(...)` |
| 外键 | 每次连接执行 `PRAGMA foreign_keys = ON` |
| 周次起算 | 第 N 周 = 位图第 (N-1) 位；全项目 1 起算 |
| 第 1 周 | 开学日期所在那一周，周一起算 |

## 2. 表结构

### 2.1 users

```sql
CREATE TABLE users (
  id          TEXT PRIMARY KEY,
  nickname    TEXT NOT NULL DEFAULT '我',
  created_at  INTEGER NOT NULL,
  updated_at  INTEGER NOT NULL,
  deleted_at  INTEGER,
  rev         INTEGER NOT NULL DEFAULT 0,
  dirty       INTEGER NOT NULL DEFAULT 0
);
```

### 2.2 semesters

```sql
CREATE TABLE semesters (
  id          TEXT PRIMARY KEY,
  user_id     TEXT NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  name        TEXT NOT NULL,
  start_date  TEXT NOT NULL,                 -- 开学日期
  total_weeks INTEGER NOT NULL DEFAULT 20 CHECK (total_weeks BETWEEN 1 AND 30),
  is_active   INTEGER NOT NULL DEFAULT 0,
  created_at  INTEGER NOT NULL,
  updated_at  INTEGER NOT NULL,
  deleted_at  INTEGER,
  rev         INTEGER NOT NULL DEFAULT 0,
  dirty       INTEGER NOT NULL DEFAULT 0
);

CREATE UNIQUE INDEX ux_semesters_active
  ON semesters(user_id) WHERE is_active = 1 AND deleted_at IS NULL;
```

### 2.3 time_slots

```sql
CREATE TABLE time_slots (
  id          TEXT PRIMARY KEY,
  semester_id TEXT NOT NULL REFERENCES semesters(id) ON DELETE CASCADE,
  period_no   INTEGER NOT NULL CHECK (period_no BETWEEN 1 AND 40),
  start_time  TEXT NOT NULL,                 -- 'HH:MM'
  end_time    TEXT NOT NULL,                 -- 'HH:MM'
  label       TEXT,
  section     TEXT CHECK (section IN ('am','pm','night')),
  created_at  INTEGER NOT NULL,
  updated_at  INTEGER NOT NULL,
  deleted_at  INTEGER,
  rev         INTEGER NOT NULL DEFAULT 0,
  dirty       INTEGER NOT NULL DEFAULT 0
);

CREATE UNIQUE INDEX ux_time_slots ON time_slots(semester_id, period_no)
  WHERE deleted_at IS NULL;
CREATE INDEX ix_time_slots_semester ON time_slots(semester_id);
```

一天的实际节次数由本表行数决定；`period_no` 上界 40 为防脏数据的粗上限。
`section` 按 `start_time` 自动推断，可手动覆盖。

### 2.4 courses

```sql
CREATE TABLE courses (
  id          TEXT PRIMARY KEY,
  semester_id TEXT NOT NULL REFERENCES semesters(id) ON DELETE CASCADE,
  name        TEXT NOT NULL,
  short_name  TEXT,
  teacher     TEXT,
  location    TEXT,                          -- 默认地点，被排课行覆盖
  color       TEXT NOT NULL DEFAULT '#4F8DFD',
  credits     REAL CHECK (credits IS NULL OR credits >= 0),
  note        TEXT,
  created_at  INTEGER NOT NULL,
  updated_at  INTEGER NOT NULL,
  deleted_at  INTEGER,
  rev         INTEGER NOT NULL DEFAULT 0,
  dirty       INTEGER NOT NULL DEFAULT 0
);

CREATE INDEX ix_courses_semester ON courses(semester_id);
```

### 2.5 course_schedules

```sql
CREATE TABLE course_schedules (
  id            TEXT PRIMARY KEY,
  course_id     TEXT NOT NULL REFERENCES courses(id) ON DELETE CASCADE,
  day_of_week   INTEGER NOT NULL CHECK (day_of_week BETWEEN 1 AND 7),
  period_start  INTEGER NOT NULL CHECK (period_start BETWEEN 1 AND 40),
  period_end    INTEGER NOT NULL CHECK (period_end   BETWEEN 1 AND 40),
  weeks_mask    INTEGER NOT NULL CHECK (weeks_mask > 0),
  weeks_raw     TEXT,                        -- 教务原文，如 '1-16周(单)'
  room          TEXT,
  created_at    INTEGER NOT NULL,
  updated_at    INTEGER NOT NULL,
  deleted_at    INTEGER,
  rev           INTEGER NOT NULL DEFAULT 0,
  dirty         INTEGER NOT NULL DEFAULT 0,
  CHECK (period_end >= period_start)
);

CREATE INDEX ix_schedules_course ON course_schedules(course_id);
CREATE INDEX ix_schedules_day    ON course_schedules(day_of_week);
```

周次位图取值：

| 周次集合 | `weeks_mask` |
|---|---|
| 第 1–16 周 | 65535 |
| 双周 2–16 | 43690 |
| 仅第 1/3/5/7 周 | 85 |

查询条件：`(weeks_mask >> (:week - 1)) & 1 = 1`

位运算封装为 `set_week(mask, week)` / `has_week(mask, week)` 两个函数使用，禁止内联裸写。

### 2.6 reminders

```sql
CREATE TABLE reminders (
  id              TEXT PRIMARY KEY,
  user_id         TEXT NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  target_type     TEXT NOT NULL CHECK (target_type IN ('course','schedule','event')),
  target_id       TEXT NOT NULL,
  advance_minutes INTEGER NOT NULL DEFAULT 10 CHECK (advance_minutes BETWEEN 0 AND 1440),
  enabled         INTEGER NOT NULL DEFAULT 1,
  skip_holidays   INTEGER NOT NULL DEFAULT 1,
  sound           INTEGER NOT NULL DEFAULT 1,
  vibrate         INTEGER NOT NULL DEFAULT 1,
  dnd             INTEGER NOT NULL DEFAULT 0,
  snooze_minutes  INTEGER CHECK (snooze_minutes IS NULL OR snooze_minutes BETWEEN 1 AND 120),
  created_at      INTEGER NOT NULL,
  updated_at      INTEGER NOT NULL,
  deleted_at      INTEGER,
  rev             INTEGER NOT NULL DEFAULT 0,
  dirty           INTEGER NOT NULL DEFAULT 0
);

CREATE INDEX ix_reminders_target ON reminders(target_type, target_id);
```

`target_id` 无外键；删除课程/排课/日程时由数据访问层清理对应提醒。

### 2.7 events

```sql
CREATE TABLE events (
  id               TEXT PRIMARY KEY,
  user_id          TEXT NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  semester_id      TEXT REFERENCES semesters(id) ON DELETE SET NULL,
  parent_id        TEXT REFERENCES events(id) ON DELETE CASCADE,
  type             TEXT NOT NULL CHECK (type IN (
                     'exam','todo','temp','reschedule','holiday','makeup','workday')),
  title            TEXT NOT NULL,
  on_date          TEXT,
  start_at         TEXT,
  end_at           TEXT,
  all_day          INTEGER NOT NULL DEFAULT 0,
  location         TEXT,
  note             TEXT,
  done             INTEGER NOT NULL DEFAULT 0,
  priority         INTEGER CHECK (priority IN (1,2,3)),
  due_at           TEXT,
  subject          TEXT,
  seat_no          TEXT,
  ref_schedule_id  TEXT REFERENCES course_schedules(id) ON DELETE CASCADE,
  action           TEXT CHECK (action IN ('move','cancel','room_change','add')),
  new_date         TEXT,
  new_period_start INTEGER CHECK (new_period_start BETWEEN 1 AND 40),
  new_period_end   INTEGER CHECK (new_period_end   BETWEEN 1 AND 40),
  new_room         TEXT,
  as_day_of_week   INTEGER CHECK (as_day_of_week BETWEEN 1 AND 7),
  source           TEXT CHECK (source IN ('builtin','manual','from_school')),
  created_at       INTEGER NOT NULL,
  updated_at       INTEGER NOT NULL,
  deleted_at       INTEGER,
  rev              INTEGER NOT NULL DEFAULT 0,
  dirty            INTEGER NOT NULL DEFAULT 0,

  CHECK (parent_id IS NULL OR parent_id <> id),
  CHECK (priority IS NULL OR type = 'todo'),
  CHECK (due_at   IS NULL OR type = 'todo'),
  CHECK (subject  IS NULL OR type = 'exam'),
  CHECK (seat_no  IS NULL OR type = 'exam'),
  CHECK (type <> 'reschedule' OR (ref_schedule_id IS NOT NULL AND action IS NOT NULL)),
  CHECK (type <> 'reschedule' OR action <> 'move' OR new_date IS NOT NULL),
  CHECK (type NOT IN ('holiday','makeup','workday') OR on_date IS NOT NULL),
  CHECK (type <> 'makeup'      OR as_day_of_week IS NOT NULL),
  CHECK (type <> 'reschedule'  OR (new_period_end IS NULL OR new_period_start IS NOT NULL)),
  CHECK (new_period_end IS NULL OR new_period_start IS NULL OR new_period_end >= new_period_start)
);

CREATE INDEX ix_events_user_time ON events(user_id, start_at);
CREATE INDEX ix_events_semester  ON events(semester_id);
CREATE INDEX ix_events_type_date ON events(type, on_date);
CREATE INDEX ix_events_parent    ON events(parent_id);
CREATE UNIQUE INDEX ux_events_day_kind
  ON events(semester_id, on_date)
  WHERE type IN ('holiday','makeup','workday') AND deleted_at IS NULL;
```

type 取值与专用字段：

| `type` | 含义 | 专用字段 |
|---|---|---|
| `exam` | 考试 | `subject`、`seat_no`、`location`（考场）、`start_at` |
| `todo` | 待办 | `priority`(1/2/3)、`due_at`、`done`、`parent_id`（子任务） |
| `temp` | 临时日程 | `start_at`、`end_at`、`all_day` |
| `reschedule` | 调课 | `ref_schedule_id`、`action`、`new_date`、`new_period_start`、`new_period_end`、`new_room`、`on_date`（原上课日） |
| `holiday` | 放假 | `on_date`、`source` |
| `makeup` | 调休补课 | `on_date`、`as_day_of_week`、`source` |
| `workday` | 明确上课日 | `on_date`、`source` |

节假日来源优先级（`source`）：`manual` > `from_school` > `builtin`。
同一 (semester_id, on_date) 仅允许一条假期/调休/上课日记录（由 `ux_events_day_kind` 强制），优先级在写入时决定：

| 情形 | 动作 |
|---|---|
| 该日期无记录 | 插入 |
| 已有记录，新来源优先级更高 | 覆盖 |
| 已有记录，新来源优先级更低或相同 | 跳过 |

子任务仅允许 `type='todo'` 的记录挂 `parent_id`，父记录也须为 `todo`；该规则由数据访问层保证。

### 2.8 app_meta

```sql
CREATE TABLE app_meta (

```

本地键值表，不参与同步，无 `rev` / `dirty`。键取值：`schema_version`、`device_id`、`sync_cursor`、`view_days`、`theme`。

## 3. 关系

```
users ─1:N─ semesters ─1:N─┬─ courses ─1:N─ course_schedules ─┐
                           └─ time_slots                       │
users ─1:N─ events ─────────(ref_schedule_id)──────────────────┘
                  └─(parent_id, 自关联)
users ─1:N─ reminders ─(弱引用)─> courses / course_schedules / events
```

## 4. 关键查询

```sql
-- 第 N 周某天的课
SELECT c.name, c.short_name, c.color, cs.period_start, cs.period_end,
       COALESCE(cs.room, c.location) AS room
FROM course_schedules cs
JOIN courses c ON c.id = cs.course_id
WHERE c.semester_id = :sid
  AND cs.day_of_week = :dow
  AND (cs.weeks_mask >> (:week - 1)) & 1 = 1
  AND cs.deleted_at IS NULL AND c.deleted_at IS NULL
ORDER BY cs.period_start;

-- 某天的放假/调休判定
SELECT type, as_day_of_week, source FROM events
WHERE semester_id = ? AND on_date = ?
  AND type IN ('holiday','makeup','workday') AND deleted_at IS NULL
ORDER BY CASE source WHEN 'manual' THEN 1 WHEN 'from_school' THEN 2 ELSE 3 END
LIMIT 1;

-- 某次课的调课覆盖
SELECT action, new_date, new_period_start, new_period_end, new_room FROM events
WHERE type = 'reschedule' AND ref_schedule_id = ? AND on_date = ? AND deleted_at IS NULL;
```

## 5. 展开（expand）

```
expand(semester_id, date_from, date_to) -> Occurrence[]

Occurrence = {
  date, period_no, start_at, end_at, course_id, room, cancelled
}
```

计算来源：`semesters.start_date`、`semesters.total_weeks`、`course_schedules.weeks_mask`、`time_slots`。
覆盖顺序：

| 来源 | 作用 |
|---|---|
| `holiday` | 当天不产生课次 |
| `makeup` | 当天按 `as_day_of_week` 指定的星期产生课次 |
| `workday` | 当天按自然星期产生课次 |
| `reschedule` + `cancel` | 对应课次置 `cancelled` |
| `reschedule` + `move` | 课次改到 `new_date` / `new_period_start` / `new_period_end` |
| `reschedule` + `room_change` | 课次教室改为 `new_room` |

结果不落库，每次现算。课表渲染、提醒调度、小组件共用同一函数。

## 6. 三端 SQLite 约束

| 端 | SQLite 载体 |
|---|---|
| Web | SQLite-WASM + OPFS |
| Windows | Tauri 2 + `tauri-plugin-sql`（sqlx） |
| Android | Capacitor + `@capacitor-community/sqlite` |

规则：

1. 建表 SQL 只用标准 SQLite 语法，不使用 `json_each`、FTS、方言扩展。
2. 迁移脚本为共享 SQL 列表（`001_init.sql` 起），由各端 applier 执行；版本号记于 `app_meta.schema_version`。
3. 业务代码经数据访问层访问数据库，不直接连驱动。
4. 每次建立连接执行 `PRAGMA foreign_keys = ON`。

## 7. 约束与已知限制

| # | 内容 |
|---|---|
| L1 | 位图按 1 起算映射到第 (N-1) 位，越界写入无数据库层校验；由 `set_week` 限制 `week ∈ [1, total_weeks]` |
| L2 | `reminders.target_id` 无外键，删除目标须由数据访问层清理 |
| L3 | 单表承载 7 种 `type`，多数行仅使用部分列 |
| L4 | 部分唯一索引与软删除并存：恢复软删除数据时可能撞唯一索引 |
| L5 | 三端 SQLite 版本与编译选项不同；本文件校验只覆盖桌面 SQLite 3.50.4 |
| L6 | `parent_id` 的父记录 `type` 必须为 `todo`，该规则无法用 `CHECK` 表达，由数据访问层保证 |
| L7 | 时刻为墙钟时间，时间戳为 UTC 毫秒；两者不可互相转换使用 |
