教学周到 iCalendar 的映射规则（来源：[RFC 5545 §3.3.10、§3.8.5.3](https://www.rfc-editor.org/rfc/rfc5545.txt)）：

| 场景 | 表达 |
|---|---|
| 单周 / 双周 | `FREQ=WEEKLY;INTERVAL=2;BYDAY=xx;UNTIL=...`，同时设置 `WKST` |
| 连续周次范围 | `DTSTART` 为第 1 周对应星期，`COUNT` 或 `UNTIL` 为末周 |
| 不连续周次集合 | 拆多个 VEVENT，或 `RRULE` 覆盖全区间加多个 `EXDATE`，或 `RDATE` 逐周枚举 |
| `BYWEEKNO` | ISO 周年周序，仅与 `FREQ=YEARLY` 搭配，不用于教学周 |
