## 0. 三句话结论（其中第一句推翻了原始假设）

1. **「导入用现成开源组件」这个假设只成立一半**：Excel/ICS 解析**确实有成熟现成库**；
   但**「教务系统课表抓取/解析」不存在任何跨校可复用的开源组件**——全是单校脚本或整套 App。
2. **RFC 5545（iCalendar 标准）里没有「教学周」这个概念**，`BYWEEKNO` 是 ISO 周年周序、不能挪用。
   单双周必须显式设置 `WKST`，不连续的周次集合**单一 RRULE 表达不了**。
   → 结论：**周次必须以晓刻自己的数据模型为真相来源**（这与我们的 SQLite 优先架构正好一致），ICS 只当编解码器。
3. **Web 端没有合适的现成课表网格组件**：现有日历组件全是「时间轴事件日历」，而我们要的是「星期 × 节次」矩阵。
   建议 **CSS Grid 手写**（几百行，完全可控、零许可证风险）。

### 2.1 「教学周」在 iCalendar 里怎么表达（已核对 RFC 5545 原文）

依据：[RFC 5545 §3.3.10 / §3.8.5.3](https://www.rfc-editor.org/rfc/rfc5545.txt)

| 场景 | 表达方式 |
|---|---|
| 单周 / 双周 | `FREQ=WEEKLY;INTERVAL=2;BYDAY=MO;UNTIL=...`。⚠ **必须同时设置 `WKST`**：RFC 原文明确 "The WKST rule part ... This is significant when a WEEKLY RRULE has an interval greater than 1"，否则按默认 MO 起算，跨学期会错位 |
| 连续周次范围（第 1–8 周） | `DTSTART` = 第 1 周该星期几，`COUNT=8` 或 `UNTIL`=第 8 周该日。注意 `COUNT` 的第一项永远是 `DTSTART` 本身 |
| **不连续周次集合（1–8、10–16）** | ❌ **单一 RRULE 无法表达**。`BYWEEKNO` 是 ISO 周年周序且只允许与 `FREQ=YEARLY` 搭配，**与教学周不是一回事**。只能：① 拆成多个 VEVENT（推荐）；② `RRULE` 覆盖全区间 + 多个 `EXDATE` 剔除；③ `RDATE` 显式枚举每周 |

**对我们的直接含义**：

- 周次集合（我们 v2 模型的 `weeks_mask`）导出成 ICS 时，**连续区段要拆成多个 VEVENT**，或统一走 `RDATE` 枚举。
- 从 ICS 反向导入时，遇到 `EXDATE`/`RDATE` 需要归并回周次集合。
- **单双周导出必须设 `WKST`**，否则别人的日历软件里单双周会整体错位一周——这是很容易漏、又很难排查的 bug。

### 3.1 ⚠ SheetJS 的真实风险（重点）

社区版虽为 Apache-2.0，但官方[许可页](https://docs.sheetjs.com/docs/miscellany/license)规定：
**必须携带指定 attribution 声明、保留版权与许可声明、修改过的源文件要注明改动**，并建议单列 open source disclosure 页面；
且**官方已弃用 GitHub/npm 分发、改走自建 CDN**（从自建 CDN 装包会绕过 lockfile 审计）；另有独立的 **SheetJS Pro 商业授权**。

→ **建议直接用 MIT 的 `exceljs`**，省掉这一串授权与审计麻烦。

### 3.2 真正的难点不是解析库

课表矩阵的业务语义**必须自己写**：左上角节次表、合并单元格造成的跨行跨列课程块、
一个单元格里多门课、以及写在文本里的「1-8周」「单周」等周次信息。
解析库只负责把单元格读出来。

## 6. 最终结论：哪些必须自己写，哪些能直接用

### 6.1 必须自己写（是产品护城河，买不到）

| # | 内容 | 原因 |
|---|---|---|
| 1 | **课表领域模型与周次/单双周语义** | RFC 5545 无「教学周」概念；ICS/Excel 都只是该模型的编解码器 |
| 2 | **教务系统适配层** | 无跨校通用库；本期建议只留插件位 |
| 3 | **Excel/CSV 二维矩阵 → 课表模型的解析器** | 业务语义（节次行头、跨行跨列、多课格、文本周次）无库可代劳 |
| 4 | **Web / Windows 课表网格 UI** | 无合适现成组件 |
| 5 | **ICS 编解码的业务映射** | 连续区段拆多 VEVENT、`EXDATE`/`RDATE` 归并、单双周设 `WKST` |
| 6 | **排课展开(expand) 与调课/调休叠加** | 见 `01` 第 5 节；课表 / 提醒 / 小组件三处必须一致 |
