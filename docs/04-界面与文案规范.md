# 04 界面与文案规范

最后更新：2026-10-16

## 0. 口径

| 项 | 规则 |
|---|---|
| 主题套数 | 四套：青春活力 `vivid`、清爽学院 `fresh`、极简墨色 `mono`、莫兰迪柔光 `muted`；默认 `vivid` |
| 深浅模式 | 每套各一版浅色与深色；`light` / `dark` / `system` 三选一，`system` 跟随系统 |
| 主题存储 | 主题名存 `app_meta.theme_preset`，深浅存 `app_meta.theme` |
| 切换入口 | 设置页「外观」卡的「主题风格」与「深浅模式」 |
| 令牌来源 | 静态令牌取自 `apps/web/src/styles.css` 的 `@theme`，颜色取自 `apps/web/src/design/tokens.ts` 的 `PRESETS` |

## 1. 设计令牌

| 令牌名 | 用途 | 取值 |
|---|---|---|
| `--font-sans` | 全局字体族 | `-apple-system`、`BlinkMacSystemFont`、`Segoe UI`、`Roboto`、`PingFang SC`、`Microsoft YaHei`、`sans-serif` |
| `--spacing-1` / `--spacing-2` / `--spacing-3` / `--spacing-4` | 紧凑间距 | 4 / 8 / 12 / 16px |
| `--spacing-6` / `--spacing-8` | 区块间距 | 24 / 32px |
| `--spacing-tap` | 触控区下限 | 44px |
| `--radius-sm` / `--radius-md` / `--radius-lg` | 圆角 | 8 / 12 / 16px；胶囊 9999px |
| `--text-xs` … `--text-2xl` | 字号 | 12 / 14 / 16 / 20 / 24 / 32px |
| `--text-*--line-height` | 对应行高 | 16 / 20 / 24 / 28 / 32 / 40px |
| `--shadow-sm` / `--shadow-md` / `--shadow-lg` | 阴影，只用于悬浮卡片与弹窗 | `0 1px 2px rgb(0 0 0 / 0.06)` / `0 4px 12px rgb(0 0 0 / 0.10)` / `0 12px 32px rgb(0 0 0 / 0.16)` |
| `--breakpoint-tablet` / `--breakpoint-desktop` | 断点 | 768px / 1024px |
| `--dt-*` | 运行时颜色变量，由 `applyTheme` 写入根节点 | 见第 2 节 |
| `--dt-course-<N>` / `--dt-course-<N>-tint` | 课程色与课程块底色 | 色板第 N 色；tint 为 `mix(surface, course-N, 0.18)` |
| `--dt-bottom-nav` / `--dt-bottom-fab` | 移动端底栏与悬浮按钮占位 | 56px |
| `.tabular` | 数字等宽对齐 | `font-variant-numeric: tabular-nums` |

Tailwind 颜色名与变量一一对应：`page`、`surface`、`surface-muted`、`line`、`line-strong`、`ink`、`muted`、`primary`、`on-primary`、`primary-strong`、`accent`、`accent-strong`、`success(-strong)`、`warning(-strong)`、`danger(-strong)`、`info(-strong)`、`overlay`。

`*Strong` 是文字与图标专用的达标变体：由原色向黑（浅底）或向白（深底）混色到 `text` 与 `bg` 达到 4.5:1；`border-strong` 由 `border` 派生到 3:1；`on-primary` 在黑与白之间择优。原色只用于填充、色条与大面积色块。

## 3. 对比度与触控尺寸

| 项 | 要求 | 检查处 |
|---|---|---|
| 正文、次要文字对背景 | ≥ 4.5:1 | `TEXT_PAIRS` 逐对断言 |
| 轮廓、焦点环、图标 | ≥ 3:1 | `UI_PAIRS` 逐对断言 |
| 填充按钮上的文字 `on-primary` 对 `primary` | ≥ 4.5:1 | `TEXT_PAIRS` 最后一条 |
| 课程块内文字 | ≥ 4.5:1，只用 `text` 或 `text` 降到 80% 不透明度 | 12 色 × 2 版逐色断言 |
| 课程块内次要文字 | 禁用 `muted`；实测最低 4.24 | 同上 |
| 点击区 | ≥ 44×44px，按钮、输入框、选择器、标签行均写 `min-h-tap` / `size-tap` | `TAP_MIN` 与 `--spacing-tap` 一致性 |

四套主题 × 深浅两版都要过全部对比度项；`tools/design/check-a11y.mjs` 校验对比度、触控尺寸与 CSS/令牌一致性。

## 4. 断点与布局

| 断点 | 宽度 | 布局口径 |
|---|---|---|
| base | < 768px | 单列为主；底栏与悬浮按钮按 56px 占位留白 |
| tablet | ≥ 768px | 列宽按屏宽等分；卡片可并排 |
| desktop | ≥ 1024px | 周视图列宽按屏宽等分显示 1–7 天，不横向滚动 |

外壳用 `fixed inset-0`，根节点 `height: 100%` 且 `overflow: hidden`，滚动只发生在主区与对话框正文区。

## 5. 动效

| 模式 | 取值 | 行为 |
|---|---|---|
| 跟随系统 | `system` | 系统「减少动态效果」开启时走停用规则 |
| 始终播放 | `full` | 不读系统偏好 |
| 关闭 | `off` | 停用规则常开 |

| 名称 | 时长与曲线 | 用途 |
|---|---|---|
| `dt-fade-in` | 150ms `ease-out` | 弹窗遮罩、忙碌蒙版、加载页入场 |
| `dt-pop-in` | 170ms `cubic-bezier(0.22, 1, 0.36, 1)` | 对话框面板入场 |
| `dt-rise-in` | 180ms 同曲线 | 底部面板入场（保留给旧调用） |
| `dt-sheet-in` | 220ms 同曲线 | 抽屉 / 底部面板上浮 + 轻微缩放 |
| `dt-card-in` | 160ms 同曲线 | 卡片、空态、列表项入场 |
| `dt-toast-in` / `dt-toast-out` | 160ms / 120ms 同曲线 | toast 进出场 |
| `dt-collapse-open` | 220ms 同曲线 | 折叠卡展开高度（Radix 高度变量） |
| `dt-view-enter` | 160ms 同曲线 | 视图切换（keyframe 为 `dt-rise-in`） |
| `dt-spin` | 700ms 线性循环 | 加载转圈 |

时长令牌：`--dt-motion-fast: 120ms`、`--dt-motion-base: 160ms`、`--dt-motion-slow: 220ms`，曲线统一 `--dt-motion-ease`；单条动画 ≤ 240ms。

交互反馈：按钮 hover / active 120ms、卡片 hover 抬升 1px + `shadow-md`、Tab 与底栏选中态 120ms（底栏顶部 2px 指示条用 `scaleX`）。新增动效只动 `transform` / `opacity` / `filter`；折叠卡高度用 Radix 的 `--radix-collapsible-content-height`，不动 width / margin。

列表入场：设置页与设备与同步页的卡片列表带 `.dt-stagger`，前 6 项按 20ms 步进依次淡入，第 7 项起延迟封顶 100ms。

停用规则把动画与过渡压到 1ms、循环次数压到 1、延迟归零，只停「动画与过渡」，不动布局；`[data-motion=off]` 与 `system` + `prefers-reduced-motion` 同时取消 hover / active 的位移，避免瞬移。

蒙版：慢操作期间用 `.dt-busy-mask` 盖住整页，`background` 取 `--dt-overlay`，挡住重复点击；同一时刻只展示一个操作名，重复触发被忽略；操作结束无论成败都收起。

加载态：蒙版容器带 `role="status"` 与 `aria-live="polite"`；按钮 `loading` 时自动禁用并加 `aria-busy`，转圈图标带 `aria-hidden`。

## 6. 文案规范

| 项 | 规则 |
|---|---|
| 说明文字 | ≤ 20 汉字，写在 `Field` 的 `hint` 里 |
| 更长说明 | 收进「?」弹层，用 `HelpHint`；不用 `title` 属性 |
| 标签 | 只用名词短语：「学期名称」「开学日期」「总周数」 |
| 错误 | 事实 + 下一步：「保存失败：磁盘只读，请换存储位置」 |
| 状态 | 只报事实：「已保存」「未申请」「连接正常，远端已有备份」 |
| 确认弹窗 | 必须保留后果说明：「将删除「X」及课程、日程与提醒，不可撤销」 |
| 删除建议句 | 句式固定为「将删除「X」及 …，不可撤销」；数量逐类列出 |
| 帮助正文 | 「?」弹层写一两句补充；正文只留动作与状态 |
| 日志 | 与文案同为一句一事实：「已删除该快照」「检查更新失败」；上下文放字段 |
| 代码注释 | 只留 1–2 行事实，不写解释 |

| 反例 | 改法 |
|---|---|
| 「本功能旨在帮助您更高效地管理课程」 | 删去，或改成「按周导入」 |
| 「操作失败」 | 补下一步：「保存失败，请检查存储位置」 |
| 「确定要删除吗？」 | 补后果：「将删除「X」及 3 条排课，不可撤销」 |
| 一行 40 字的说明留在正文 | 移到 `help` |

## 7. 图标与组件来源

| 类别 | 来源 | 用法 |
|---|---|---|
| 图标 | `lucide-react` | 图标按钮必须带 `aria-label`；装饰性图标带 `aria-hidden` |
| 基元 | Radix：`react-dialog`、`react-popover`、`react-select`、`react-switch`、`react-slot` | 焦点管理与读屏语义交给基元 |
| 变体 | `class-variance-authority` | 按钮等组件的 `variant` / `size` |
| 类名合并 | `clsx` + `tailwind-merge`（`lib/cn.ts`） | 组件外部传入的 `className` 覆盖内部类 |

| 组件 | 位置 |
|---|---|
| `Field`（`label` / `hint` / `help`） | `apps/web/src/components/ui/input.tsx` |
| `HelpHint`（「?」弹层） | `apps/web/src/components/ui/help-hint.tsx` |
| `Button` | `apps/web/src/components/ui/button.tsx` |
| `Dialog` / `DialogContent` / `DialogFooter` | `apps/web/src/components/ui/dialog.tsx` |
| `BusyOverlay` | `apps/web/src/components/ui/busy-overlay.tsx` |
