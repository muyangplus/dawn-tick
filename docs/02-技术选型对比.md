# 晓刻 — 技术选型对比

最后更新：2026-10-10 ｜ 决策见 `00-项目说明与已确认决策.md` 的 D24–D29

## 1. 硬需求对选型的约束

| 需求 | 达成条件 |
|---|---|
| Windows 11 小组件面板 | 官方限定仅 MSIX 打包应用可注册为提供程序 |
| 安卓主屏小组件 | 需原生 Kotlin 编写 AppWidget / Glance |
| 应用关闭后仍准时提醒 | Android 走 AlarmManager 精确闹钟；Windows 无定时通知 API，需常驻进程 |
| 三端共用界面代码 | 需 Web 技术栈的桌面壳与移动壳 |

## 2. 五个方向事实对比

| 对比项 | A. Flutter 三端 | B. React/Tauri/Kotlin | C. Electron/React + Kotlin | D. RN / Expo | E. 原生 WinUI3 + React + Kotlin |
|---|---|---|---|---|---|
| 本地 SQLite | [drift](https://drift.simonbinder.eu/platforms/)（MIT），三端含 Web(WASM) | Windows [tauri-plugin-sql](https://v2.tauri.app/plugin/sql/)（Rust ≥1.90）、Android [Room](https://developer.android.com/reference/android/arch/persistence/room/RoomDatabase.Builder) | better-sqlite3（需按 Electron ABI 重编）、Android Room | [expo-sqlite](https://docs.expo.dev/versions/latest/sdk/sqlite/) 平台列表不含 Windows；Web 为 alpha | WinUI3 EF Core / Microsoft.Data.Sqlite、Android Room |
| 迁移支持 | drift 内置 | 插件内置 / Room 内置 | 无内置 | 无内置 | EF Core Migrations |
| 应用关闭后提醒（Windows） | 需 MSIX 打包才可管理通知（[来源](https://pub.dev/packages/flutter_local_notifications_windows)） | 官方通知插件标注 "Only works for installed apps"（[来源](https://v2.tauri.app/plugin/notification/)）；官方路径为 WinAppSDK 计划通知 | 官方 Notification API 无定时参数 | 无 Windows 桌面平台 | WinAppSDK 计划通知（[来源](https://learn.microsoft.com/en-us/windows/apps/develop/notifications/app-notifications/app-notifications-scheduled)） |
| Windows 11 小组件 | 无官方路径 | 需独立 C# COM provider + MSIX | 无现成方案 | 不可能 | 官方一等路径（[来源](https://learn.microsoft.com/en-us/windows/apps/develop/widgets/implement-widget-provider-cs)） |
| Android 主屏小组件 | 需原生 Kotlin（[home_widget](https://pub.dev/packages/home_widget) 文档载明需原生编写） | 需原生 Kotlin | 需原生 Kotlin | 需原生 Kotlin + 桥接 | 需原生 Kotlin |
| iOS 后路 | 需 Swift 重写 | 需第四套 Swift | 需第三套 Swift | 同栈加平台 | 需第四套 Swift |
| 本机需补装 | Flutter SDK、Android SDK、VS + C++ 工作负载（[来源](https://docs.flutter.dev/platform-integration/windows/setup)） | Rust ≥1.90、MSVC（[来源](https://v2.tauri.app/start/prerequisites/)）、Android SDK | VS Build Tools、Android SDK | Android SDK | VS + WinUI/Windows App SDK、Android SDK |
| Android 定时通知 | flutter_local_notifications 的 `zonedSchedule` | 官方通知插件无定时 API | 无 | expo-notifications | 原生 AlarmManager |

### 2.1 Capacitor 与 Tauri 在 Android 的能力对比

| 维度 | Tauri 2 | Capacitor |
|---|---|---|
| 定时通知 | 官方[通知插件](https://v2.tauri.app/plugin/notification/)仅发送，无定时 API | 官方 [`@capacitor/local-notifications`](https://capacitorjs.com/docs/apis/local-notifications) 提供 `schedule()`，含 `SCHEDULE_EXACT_ALARM`、`USE_EXACT_ALARM`、`allowWhileIdle`、`checkExactNotificationSetting()` |
| 本地 SQLite | [tauri-plugin-sql](https://v2.tauri.app/plugin/sql/) 含 android，内置迁移 API | `@capacitor-community/sqlite` |
| Windows 桌面 | 支持；官方[托盘](https://v2.tauri.app/learn/system-tray/)、[开机自启](https://v2.tauri.app/plugin/autostart/)插件 | 官方支持状态未确证（`ionic.io/docs/windows` 抓取失败） |

## 3. 官方限制

| # | 内容 | 来源 |
|---|---|---|
| L1 | "In the current release, only packaged apps can be registered as widget providers." | [Microsoft Learn](https://learn.microsoft.com/en-us/windows/apps/develop/widgets/implement-widget-provider-cs) |
| L2 | "Scheduled app notifications have a delivery window of 5 minutes." 关机或睡眠超过 5 分钟的通知会被丢弃；官方建议改用 time-trigger 后台任务 | [Microsoft Learn](https://learn.microsoft.com/en-us/windows/apps/develop/notifications/app-notifications/app-notifications-scheduled) |
| L3 | "Without a valid shortcut installed in the Start screen or in All Programs, you cannot raise a toast notification from a desktop app." | [Microsoft Learn](https://learn.microsoft.com/en-us/windows/win32/shell/enable-desktop-toast-with-appusermodelid) |
| L4 | Android 14 起精确闹钟默认被拒绝；`USE_EXACT_ALARM` 为受限权限，仅核心功能需要时可声明 | [Android](https://developer.android.com/about/versions/14/changes/schedule-exact-alarms)、[Play 政策](https://support.google.com/googleplay/android-developer/answer/15225428) |

## 4. 选定组合

| 端 | 技术 |
|---|---|
| 界面 | React + TypeScript，三端共用 |
| Windows 壳 | Tauri 2（D25） |
| Android 壳 | Capacitor（D26） |
| Web | 浏览器，SQLite-WASM + OPFS（D27） |

对应约束：

1. 两套壳的插件 API 由平台适配层隔离。
2. Windows 常驻托盘 + 开机自启（D29）。
3. Android 申报 `USE_EXACT_ALARM`。
