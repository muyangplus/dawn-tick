# 07 发布与版本规范

## 1. 渠道

| 渠道 | 来源分支 | 预发布 | 标签格式 |
|---|---|---|---|
| release | `main` | 否 | `vX.Y.Z` |
| beta | `beta` | 是 | `vX.Y.Z-beta.<run_number>` |
| dev | `dev` | 是 | `vX.Y.Z-dev.<run_number>` |

## 2. 版本号

| 位置 | 字段 | 写入方 |
|---|---|---|
| `package.json` | `version` | 唯一来源，手工修改 |
| `apps/web/package.json` | `version` | `tools/release/version.mjs` |
| `apps/desktop/src-tauri/tauri.conf.json` | `version` | `tools/release/version.mjs` |
| `apps/desktop/src-tauri/Cargo.toml` | `[package] version` | `tools/release/version.mjs` |
| `apps/mobile/android/app/build.gradle` | `versionName` / `versionCode` | `tools/release/version.mjs`，`versionCode = major*10000 + minor*100 + patch` |

## 3. 触发

| 事件 | 渠道 | 行为 |
|---|---|---|
| push `main` | release | 读取版本号，标签 `vX.Y.Z` 不存在则创建标签并发布；已存在则覆盖该 Release 的产物 |
| push `beta` | beta | 发布 `vX.Y.Z-beta.<run_number>` 预发布 |
| push `dev` | dev | 发布 `vX.Y.Z-dev.<run_number>` 预发布 |
| push 标签 `v*` | 按标签后缀 | 沿用该标签发布（`vX.Y.Z` 正式，`-beta.`/`-dev.` 预发布） |
| 手动触发 | 下拉选择 | 覆盖分支推断 |

## 4. 产物

| 文件 | 来源 |
|---|---|
| `晓刻-<version>-<channel>-windows-x64-setup.exe` | `tauri build` 的 NSIS 安装包 |
| `晓刻-<version>-<channel>-android.apk` | `assembleRelease`（无签名材料时为 `assembleDebug`） |
| `晓刻-<version>-<channel>-web.zip` | `apps/web/dist` |
| `SHA256SUMS.txt` | 上述产物的 SHA256 |

发布说明由 GitHub 按提交与 PR 自动生成。

## 5. 预发布保留

| 渠道 | 保留数量 |
|---|---|
| dev | 最新 1 个 |
| beta | 最新 5 个 |

## 6. 密钥

| GitHub Secret | 内容 |
|---|---|
| `ANDROID_KEYSTORE_BASE64` | `dawn-tick-release.key` 的 base64 |
| `ANDROID_KEYSTORE_PASSWORD` | 密钥库口令 |
| `ANDROID_KEY_ALIAS` | 密钥别名 |
| `ANDROID_KEY_PASSWORD` | 密钥口令 |

密钥库文件为 `.key` 后缀，位于 `E:\work\dsh\dawn-tick-keys\`（仓库之外），`.gitignore` 另有 `*.key`、`*.jks`、`*.keystore`、`*.p12`、`/keys/` 规则兜底。四个 Secret 均未配置时，Android 产物为 debug 包。

## 7. 本地命令

| 命令 | 作用 |
|---|---|
| `pnpm version:current` | 打印当前版本号 |
| `pnpm version:set 0.2.0` | 同步写入五处版本号 |
| `pnpm version:check` | 校验五处版本号一致，不一致退出码 1 |
| `node tools/release/plan.mjs --ref=refs/heads/dev --run=1` | 预览渠道与标签 |
| `node --test tools/release/plan.test.mjs` | 发布规则自测 |
| `powershell -File tools/setup/make-android-keystore.ps1` | 生成本地签名密钥库 |
| `powershell -File tools/verify/verify-all.ps1` | 三端产物与测试总校验 |

## 8. 分支

| 分支 | 用途 |
|---|---|
| `main` | 正式版来源，只接受 PR 合并 |
| `beta` | 公测版来源 |
| `dev` | 开发版来源，日常提交落点 |

## 9. 仓库设置（需在 GitHub 网页端开启）

| 项 | 值 |
|---|---|
| Actions 权限 | Settings → Actions → General → Workflow permissions 设为 Read and write |
| main 分支保护 | Require a pull request before merging；Require status checks：`测试与类型检查`、`数据模型跨引擎校验`、`Rust 壳与 DDL 校验` |
| Secrets | 见第 6 节四个 Secret（未配置时 Android 走 debug 包） |
