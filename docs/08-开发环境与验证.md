# 08 开发环境与验证

## 1. 工具链

| 组件 | 版本 | 用途 |
|---|---|---|
| Node | 24 | 原生 TypeScript 类型擦除，`node --test` 直接执行 `.ts` |
| pnpm | 12.6.0 | 由 `packageManager` 字段固定 |
| Rust | 1.99 | Tauri 壳 |
| JDK | 21 | Capacitor 插件要求 Java 21 工具链 |
| Android SDK | `platforms;android-36`、`build-tools;35.0.0` | Android 与小组件构建 |
| Gradle | 8.14.3 | 随 Android 工程 wrapper 提供 |
| Python | 3.14 | `tools/schema-check` 与工作流 YAML 校验 |

## 2. 镜像与网络

| 组件 | 配置 |
|---|---|
| Rust | `~/.cargo/config.toml` 指向 USTC 稀疏索引；`NO_PROXY` 需含镜像域（cargo 会读注册表代理） |
| Node | `registry.npmmirror.com` |
| Gradle 发行包 | `mirrors.cloud.tencent.com/gradle/`，`networkTimeout=60000` |
| Maven | 阿里云 `public` / `google` / `gradle-plugin` 镜像优先 |
| NSIS | `TAURI_BUNDLER_TOOLS_GITHUB_MIRROR=https://ghproxy.net/https://github.com` |

## 3. 脚本

| 脚本 | 作用 |
|---|---|
| `tools/setup/setup-mirrors.ps1` | 写入各包管理器镜像配置 |
| `tools/setup/install-rust.ps1` | 安装 Rust |
| `tools/setup/install-android-sdk.ps1` | 安装 Android SDK 与构建工具 |
| `tools/setup/install-jdk21.ps1` | 免安装 JDK 21 |
| `tools/setup/make-icons.mjs` | 生成应用图标（ICO 与 PNG） |
| `tools/setup/make-android-keystore.ps1` | 生成 Android 签名密钥到 `keys/` |
| `tools/verify/verify-all.ps1` | 一键验证 |
| `tools/release/version.mjs` | 版本号同步与一致性校验 |
| `tools/release/plan.mjs` | 发布渠道、标签与构建引用计算 |

## 4. 验证

`powershell -File tools/verify/verify-all.ps1` 逐项输出 `[PASS] / [FAIL] / [SKIP]`，任一 FAIL 退出码为 1。

| 项 | 覆盖 |
|---|---|
| core 测试 | 数据模型、展开、同步、校验、导入导出、提醒、备份 |
| web 测试 | IndexedDB 存储、界面数据流、小组件快照、提醒链路 |
| 类型检查 | 工作区全部 TypeScript |
| 数据模型校验 | `001_init.sql` 约束在 Python SQLite 上逐条复验 |
| Web 构建 | `index.html` 与 `mini.html` 双入口 |
| Windows 产物 | 独立 exe 与 NSIS 安装包 |
| Android 产物 | APK 内的小组件类、清单声明与前端资源 |
| Rust 壳 | `cargo check --all-targets` 与 DDL 测试 |

发布侧另有自测：`node --test tools/release/plan.test.mjs tools/release/ci-gate.test.mjs`，覆盖渠道与标签计算、以及 CI 闸门的判定与轮询。

## 5. 密钥

| 文件 | 位置 | 是否入库 |
|---|---|---|
| 签名密钥库 | `keys/dawn-tick-release.key` | 否 |
| 密钥口令 | `keys/keystore.properties` | 否 |
| GitHub Secrets | `ANDROID_KEYSTORE_BASE64` 等四个 | 存于仓库设置 |

`.gitignore` 排除规则：`/keys/`、`*.key`、`*.jks`、`*.keystore`、`*.p12`、`*.pfx`、`*.pem`、`keystore.properties`。

## 6. 环境坑

| 现象 | 处理 |
|---|---|
| MSVC 14.51 编译 `libsqlite3-sys` 报 `cl.exe D8050` | Cargo 配置 `[profile.dev] debug = 0` 与 `[profile.test] debug = 0` |
| Gradle 发行包下载 0 字节 | 改走腾讯镜像并提高 `networkTimeout` |
| 插件要求 `languageVersion=21` 而本机只有 17 | 免安装 Microsoft OpenJDK 21 并登记 `org.gradle.java.installations.paths` |
| `.kt` 文件被静默忽略 | app 模块应用 `org.jetbrains.kotlin.android` 插件 |
| Kotlin 与 Java 目标不一致 | `jvmTarget` 对齐 Capacitor 生成的 Java 21 |
| Linux 上 `./gradlew` 报 Permission denied | 增加 Git 可执行位，并以 `sh ./gradlew` 调用 |
| PowerShell 5.1 读取 UTF-8 脚本乱码 | 脚本保存为带 BOM 的 UTF-8 |
| `services.gradle.org`、`github.com` 直连超时 | 分别改用腾讯镜像与 `ghproxy.net` |
