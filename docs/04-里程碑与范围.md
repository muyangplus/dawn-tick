## 3. 里程碑

### M0 方案确认
| 项 | 内容 |
|---|---|
| 状态 | 已完成（2026-10-10） |

### M1 仓库骨架与跨三端 SQLite
| 项 | 内容 |
|---|---|
| 交付物 | monorepo 结构；数据访问层；`001_init.sql` 迁移脚本与版本管理；单元测试框架 |
| 验收 | 存储抽象层（`Storage` / `Collection`）在内存、SQLite、IndexedDB 三种实现上均通过同一批业务逻辑测试；同步框架本机跑通；数据模型 CRUD 单测通过 |
| 依赖 | M0 |
| 需装工具链 | Node（已有）、Rust ≥1.90、Android SDK + Gradle |
| 风险 | 三端 SQLite 版本与编译选项差异；OPFS 需跨源隔离响应头 |

### M2 课表核心
| 项 | 内容 |
|---|---|
| 交付物 | 周视图（CSS Grid，天数可选 5/6/7，默认 5）、今日视图、课程详情、颜色标记；首次启动引导新建学期；四套内置主题与夜间模式；展开（expand）函数；周次与当前周次计算 |
| 验收 | 固定样例（连续周次、双周、碎片周次、连堂、放假、调休补课、调课）渲染结果正确；`set_week` / `has_week` 单测通过 |
| 依赖 | M1 |
| 风险 | 展开函数为最复杂逻辑；周次、调休、调课、节次四者叠加 |

### M3 课表导入
| 项 | 内容 |
|---|---|
| 交付物 | ICS 导入导出、CSV/Excel 二维矩阵导入、手动添加；教务抓取仅留接口位 |
| 验收 | 各格式真实样例导入成功；重复导入幂等；ICS 导出后再导入周次语义不变 |
| 依赖 | M2 |
| 组件 | exceljs、ical.js、rrule、PapaParse（见 `03-开源组件调研.md`） |
| 风险 | ICS 单双周需设 `WKST`；不连续周次需拆多个 VEVENT 或 `RDATE` 枚举；矩阵解析业务语义需自研 |

### M4 课前提醒
| 项 | 内容 |
|---|---|
| 交付物 | 课前 5/10/15/30 分钟与自定义；节假日跳过；声音/震动、勿扰联动、贪睡；首次导入后请求通知权限 |
| 分端实现 | Android：Capacitor `@capacitor/local-notifications`，申报 `USE_EXACT_ALARM`；Windows：常驻托盘 + 开机自启；Web：浏览器通知 |
| 验收 | 各端在应用未打开时准时提醒；调休日与放假日不误提醒 |
| 依赖 | M2、M3 |
| 风险 | Windows 计划通知有 5 分钟投递窗口；Web 端页面关闭后无法提醒 |

### M5 悬浮窗与小组件
| 项 | 内容 |
|---|---|
| 交付物 | 下一节课、今日课表、一周概览、考试倒计时 |
| 分端形态 | Windows：紧凑悬停条（约 220px，可拖动、吸附边缘、双击折叠）+ 托盘；Android：2×2「下一节课」与 4×2「今日课表」两种主屏小组件（原生 Kotlin）；Web：页面内组件 |
| 刷新 | 30 分钟周期 + 数据变更即时刷新 + 课前 5 分钟由精确闹钟补一次 |
| 验收 | 数据变更后各端显示刷新到最新 |
| 依赖 | M2 |
| 风险 | Android 小组件为本期唯一原生开发工作 |

### M6 打磨与发布
